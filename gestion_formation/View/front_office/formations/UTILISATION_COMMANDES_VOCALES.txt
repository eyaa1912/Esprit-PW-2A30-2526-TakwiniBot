🚀 COMMENT UTILISER ?
────────────────────────────────────────────────────────────────

1. OUVRIR UNE PAGE
   → http://localhost/.../formation.php
   OU double-cliquez sur : demo-commandes-vocales.html

2. TROUVER LE BOUTON VERT 🎤
   → En bas à droite de la page (au-dessus du bouton violet)

3. CLIQUER SUR LE BOUTON VERT
   → Le bouton devient ROUGE
   → Message : "Je vous écoute"
   → Indicateur : "🎤 J'écoute..."

4. PARLER CLAIREMENT
   → Dites une des commandes ci-dessous
   → Exemple : "formation"

5. L'ACTION S'EXÉCUTE !
   → Le système répond : "Navigation vers formation"
   → La page formations s'ouvre automatiquement !


📋 COMMANDES DISPONIBLES
────────────────────────────────────────────────────────────────

🏠 ALLER À L'ACCUEIL
   Dites : "accueil" OU "home" OU "maison"
   → Va à la page d'accueil

ℹ️ ALLER À PROPOS
   Dites : "about" OU "à propos" OU "apropos"
   → Va à la page à propos

📚 ALLER AUX FORMATIONS
   Dites : "formation" OU "formations"
   → Va à la page formations

📝 ALLER AUX RÉCLAMATIONS
   Dites : "réclamation" OU "réclamations"
   → Va à la page réclamations

✍️ OUVRIR FORMULAIRE INSCRIPTION
   Dites : "inscription" OU "inscrire" OU "s'inscrire"
   → Ouvre le formulaire d'inscription

🔐 SE CONNECTER
   Dites : "se connecter" OU "connecter" OU "connexion" OU "login"
   → Clique sur le bouton de connexion

❓ VOIR L'AIDE
   Dites : "aide" OU "help" OU "commandes"
   → Affiche toutes les commandes disponibles

⏹️ ARRÊTER
   Dites : "arrêter" OU "stop" OU "fermer"
   → Arrête l'écoute du microphone

🎨 INTERFACE
────────────────────────────────────────────────────────────────

DEUX BOUTONS EN BAS À DROITE :

1. BOUTON VIOLET (🔊) - Lecture de texte
   → Passe curseur sur texte = Il est lu

2. BOUTON VERT (🎤) - Commandes vocales
   → Clic = Parle = Action exécutée

ÉTATS DU BOUTON VERT :
  • VERT 🎤 = En attente (cliquez pour parler)
  • ROUGE 🎤 = En écoute (parlez maintenant !)
  • "🎤 J'écoute..." = Le système vous écoute

🔧 PROBLÈMES COURANTS
────────────────────────────────────────────────────────────────

❌ BOUTON N'APPARAÎT PAS
   → Utilisez Chrome ou Edge
   → Vérifiez que voice-commands.js existe
   → Ouvrez console (F12) pour voir erreurs

❌ MICROPHONE NE FONCTIONNE PAS
   → Cliquez sur 🔒 dans barre d'adresse
   → Autorisez l'accès au microphone
   → Testez votre micro dans paramètres Windows

❌ COMMANDES NON RECONNUES
   → Parlez clairement et pas trop vite
   → Attendez "Je vous écoute"
   → Vérifiez l'indicateur "🎤 J'écoute..."
   → Essayez une autre formulation

❌ PAS DE SON
   → Vérifiez volume ordinateur
   → Vérifiez haut-parleurs
   → Installez voix françaises
