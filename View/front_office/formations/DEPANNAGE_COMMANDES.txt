❌ PROBLÈME : "Formulaire inscription non trouvé"
────────────────────────────────────────────────────────────────

CAUSE : Le système ne trouve pas le modal d'inscription sur la page

SOLUTIONS :

✅ Solution 1 : Tester sur la bonne page
   1. Ouvrir : test-commandes.html
   2. Cliquer sur bouton vert 🎤
   3. Dire : "inscription"
   4. ✅ Le modal devrait s'ouvrir !

✅ Solution 2 : Vérifier que le modal existe
   1. Ouvrir la page dans le navigateur
   2. Appuyer sur F12 (console)
   3. Taper : document.getElementById('inscriptionModal')
   4. Si "null" → Le modal n'existe pas sur cette page
   5. Si objet → Le modal existe

✅ Solution 3 : Utiliser formation.php
   1. Ouvrir : http://localhost/.../formation.php
   2. Vérifier qu'il y a des formations affichées
   3. Cliquer sur bouton vert 🎤
   4. Dire : "inscription"
   5. Le premier modal devrait s'ouvrir

✅ Solution 4 : Cliquer manuellement d'abord
   1. Cliquer sur un bouton "Inscription" sur la page
   2. Vérifier que le modal s'ouvre
   3. Fermer le modal
   4. Essayer la commande vocale
   5. Si ça marche → Le modal existe
   6. Si ça ne marche pas → Problème de code


❌ PROBLÈME : Le bouton vert n'apparaît pas
────────────────────────────────────────────────────────────────

SOLUTIONS :

✅ Vérifier le navigateur
   → Utilisez Chrome ou Edge (PAS Firefox)

✅ Vérifier que le script est chargé
   1. F12 → Console
   2. Chercher : "Commandes vocales activées"
   3. Si absent → Le script n'est pas chargé

✅ Vérifier Font Awesome
   → Le fichier assets/fonts/font-awesome.min.css doit exister


❌ PROBLÈME : Le microphone ne fonctionne pas
────────────────────────────────────────────────────────────────

SOLUTIONS :

✅ Autoriser le microphone
   1. Cliquer sur 🔒 dans la barre d'adresse
   2. Autoriser le microphone
   3. Recharger la page

✅ Tester le microphone
   → Paramètres Windows → Son → Microphone
   → Parler et vérifier les barres


❌ PROBLÈME : Commande non reconnue
────────────────────────────────────────────────────────────────

SOLUTIONS :

✅ Parler clairement
   → Pas trop vite, pas trop lent
   → Articuler bien

✅ Attendre "Je vous écoute"
   → Ne parlez qu'après ce message

✅ Vérifier l'indicateur
   → "🎤 J'écoute..." doit être affiché

✅ Essayer d'autres formulations
   → "inscription" OU "inscrire" OU "s'inscrire"
